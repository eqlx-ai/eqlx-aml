# Security

This library reads transfer files that may contain personal or confidential data, and its MCP server
gives an AI agent read access to a folder. If you find a way to make it read outside that folder, reach
the network, run code or exhaust memory, or a detector that silently misses a pattern its definition
covers, please do not open a public issue. Write to research@eqlx.ai or use GitHub's "Report a
vulnerability" button on the Security tab. Never send real transaction data; describe the structure or
reproduce it with `eqlx_aml.synthetic`. We aim to reply within five working days.
